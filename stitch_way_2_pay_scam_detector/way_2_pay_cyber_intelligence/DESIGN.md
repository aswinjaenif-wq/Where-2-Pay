## Brand & Style

This design system establishes an enterprise-grade visual standard for real-time payment telemetry, fraud heuristics, and automated transaction protection. It blends technical precision with institutional security aesthetics, positioning the interface as a reliable defensive perimeter before capital movement occurs.

### Tone & Personality
- **Sovereign Trust & Defense:** The interface projects uncompromised institutional security, architectural stability, and mathematical certainty.
- **Cognitive Clarity:** Visual noise is stripped away in favor of high-legibility telemetry, immediate threat identification, and structured data hierarchy.
- **Surgical Modernism:** Aesthetic elements borrow from modern network operations centers (NOCs) and institutional trading desks, utilizing controlled cyan luminescences over obsidian and deep slate substrates.

### Design Movement
The system operates at the intersection of **Dark Glassmorphism** and **Technical Minimalism**:
- Translucent dark layers with precise sub-pixel perimeter borders (`1px rgba(255, 255, 255, 0.08)`).
- Subdued ambient cyan/blue glows providing contextual illumination for key states without causing visual fatigue.
- Dense, tabular data presentation balanced by spacious layout scaffolding to allow immediate risk classification without cognitive strain.

## Colors

The color architecture is built around deep, light-absorbent dark surfaces layered with selective chromatic accents to guide immediate attention to threat levels and verification telemetry.

### Palette Roles
- **Canvas & Surface Architecture:**
  - Base Ground: `#0A0F1D` (Deep void navy, zero bounce)
  - Primary Container: `#0F172A` (Elevated substrate)
  - Card & Interactive Surface: `#1E293B` (High-tier paneling)
  - Sub-pixel Border / Glass Stroke: `#334155` (Base outline) and `rgba(255, 255, 255, 0.08)` (Reflective rim)
- **Brand & Action Signals:**
  - Primary Accent: `#06B6D4` (Cyber Cyan) — signifies active scanning, verification processes, telemetry badges, and primary calls-to-action.
  - Secondary Accent: `#3B82F6` (Electric Tech Blue) — used for protocol metadata, standard links, and informational state matrices.
- **Threat Vector / Risk Classification Engine:**
  - Safe / Verified (Low Risk): `#10B981` (Emerald) — 0–15% Scam Probability.
  - Caution / Advisory (Medium Risk): `#F59E0B` (Amber) — 16–60% Scam Probability.
  - Critical / Threat Vector (High Risk): `#EF4444` (Crimson) — 61–100% Scam Probability.
- **Text & Foreground Hierarchy:**
  - High Emphasis: `#F8FAFC` (Pure Titanium, 98% opacity)
  - Muted Telemetry: `#94A3B8` (Slate Neutral, 60% opacity)
  - Inactive / Gridlines: `#475569` (Subtle boundary, 30% opacity)

## Typography

The typographical system enforces strict functional delineation across three specialized type families:

1. **Plus Jakarta Sans (Headings & Structural Anchors):** Provides humanized geometric authority. Kerning is deliberately pulled tight (`-0.01em` to `-0.03em`) on large numbers and summary titles to communicate solidity and certainty.
2. **Inter (Body, Analysis Descriptions, Forms):** Utilized for continuous reading, micro-copy, explanations of risk rules, and audit logs due to its optical clarity at dense scales on LCD screens.
3. **JetBrains Mono (Telemetry, Hash Digests, Transaction Data):** Strict monospacing applied to wallet addresses, payment routing numbers, heuristic confidence percentages (e.g., `99.4%`), latency indicators, and cryptographic validations.

### Typographic Rules
- Never use all-caps on body text or headlines. Uppercase is strictly reserved for `JetBrains Mono` tags, protocol badges, and status labels (e.g., `AES-256`, `CRITICAL`, `DNS_FAIL`).
- Tabular figures (`font-variant-numeric: tabular-nums`) must be active for all numeric data rows to prevent layout jitter during live telemetry updates.

## Layout & Spacing

The layout model is anchored to an uncompromising 8px baseline grid, utilizing an adaptive 12-column responsive system engineered for high data density.

### Grid & Breakpoints
- **Desktop (1280px and above):** 12-column fluid grid, `margin: 3rem`, `gutter: 1.5rem`. Layout maintains a maximum content container width of `1440px` to guarantee glanceability across ultra-wide monitors.
- **Tablet / Operational Console (768px – 1279px):** 8-column layout, `margin: 2rem`, `gutter: 1.25rem`. Complex dual-column audit trails collapse into contextual master-detail views.
- **Mobile (320px – 767px):** 4-column layout, `margin-mobile: 1rem`, `gutter-mobile: 1rem`. Critical scam alert meters stay pinned top-of-screen; deep technical metrics stack sequentially.

### Spacing Principles
- Density communicates rigor: Component-internal padding adheres to compact multiples (`space-sm` for list items, `space-md` for form fields).
- Structural breathing room: Generous outer margins (`space-xl` to `margin`) frame the data density, preventing visual fatigue during extended audit sessions.

## Elevation & Depth

Visual depth is achieved through translucent dark layering, physical edge highlighting, and controlled photonic emission, completely replacing muddy drop-shadows with structured radiance.

### Surface Tiers
- **Tier 0 (Background Canvas):** Solid `#0A0F1D`. Absorbs light; provides the grounding plane.
- **Tier 1 (Panels & Shell):** `#0F172A` with `backdrop-filter: blur(12px)` and a continuous structural border of `1px solid rgba(255, 255, 255, 0.05)`.
- **Tier 2 (Floating Action Cards & Threat Modules):** `#1E293B` at 80% opacity, bordered by `1px solid rgba(255, 255, 255, 0.1)`.
- **Tier 3 (Modals & Overlays):** Surface `#1E293B` elevated with a double-ring perimeter: an interior `inset 0 1px 0 rgba(255, 255, 255, 0.15)` coupled with a deep drop shadow: `0 20px 40px -15px rgba(0, 0, 0, 0.7)`.

### Chromatic Glows & Edge Treatment
- **Safe State:** Edge stroke transitions to `rgba(16, 185, 129, 0.4)` with an ambient back-glow of `0 0 24px -4px rgba(16, 185, 129, 0.15)`.
- **Critical Risk State:** Edge stroke changes to `rgba(239, 68, 68, 0.6)` with an assertive, pulsing ambient back-glow: `0 0 32px -4px rgba(239, 68, 68, 0.25)`.
- **System Active / Processing:** Edge highlights emit a concentrated Cyan bloom: `0 0 20px -2px rgba(6, 182, 212, 0.2)`.

## Shapes

The interface balances soft human accessibility with sharp analytical exactitude:

- **Large Contextual Containers & Scam Alert Cards:** Configured with `rounded-2xl` (`1.5rem` / `24px`) to establish friendly, protective perimeters around security-sensitive interactions.
- **Interactive Controls (Buttons, Inputs, Metric Badges):** Standardized on `0.5rem` (`8px`) to maintain structured, tool-like precision.
- **Telemetry Chips & Status Pills:** Configured with complete pill profiles (`rounded-full`) to contrast immediately against the strict Cartesian matrix of the analytical dashboard.

## Components

### Buttons & Interactive Triggers
- **Primary Cyber-Action (e.g., "Verify Transaction", "Deploy Guard"):** Background linear-gradient from `#06B6D4` to `#0891B2`. Text in `#0A0F1D` (Jet Black, semi-bold). On hover: glow expands (`0 0 16px rgba(6, 182, 212, 0.4)`), scale `1.01`.
- **Secondary / Defensive:** Transparent background, `1px solid rgba(255, 255, 255, 0.15)`, text `#F8FAFC`. On hover: background shifts to `rgba(255, 255, 255, 0.05)`, border shifts to `#06B6D4`.
- **Destructive / Abort Transfer:** Crimson gradient from `#EF4444` to `#B91C1C`. High-contrast warning state with active confirmation state.

### Threat & Risk Indicator Chips
- Structured with a monospaced dot indicator, uppercase text, and an ambient background tint:
  - **LOW RISK:** Dot `#10B981` with pulse, text `#10B981`, background `rgba(16, 185, 129, 0.1)`, border `1px solid rgba(16, 185, 129, 0.2)`.
  - **MEDIUM RISK:** Dot `#F59E0B`, text `#F59E0B`, background `rgba(245, 158, 11, 0.1)`, border `1px solid rgba(245, 158, 11, 0.2)`.
  - **CRITICAL ALERT:** Dot `#EF4444` with rapid flash, text `#EF4444`, background `rgba(239, 68, 68, 0.15)`, border `1px solid rgba(239, 68, 68, 0.3)`.

### Form & Input Fields (Payment Intercept)
- Background `#0A0F1D`, inset border `1px solid #334155`. Text in titanium white with placeholder in muted slate (`#475569`).
- Focus state: Border smoothly illuminates to `#06B6D4` accompanied by a localized inner shadow `inset 0 0 8px rgba(6, 182, 212, 0.1)`.
- Integrated input appendages include monospaced protocol indicators (e.g., `IBAN:`, `ETH:`, `CARD:`) styled in muted `JetBrains Mono`.

### Scam Detection & Heuristic Cards
- Constructed with `rounded-2xl` architecture on `#0F172A`.
- Header section incorporates a dynamic threat level bar (2px height) running across the top edge.
- Inner data compartmentalized into alternating sub-panels with `rgba(255, 255, 255, 0.02)` backgrounds, presenting verification latency, machine-learning confidence scores, and domain age analytics.

### Micro-Interactions & State Changes
- All state transitions strictly constrained to `150ms` cubic-bezier (`0.4, 0, 0.2, 1`) to ensure response feels instantaneous and military-grade.
- Live scan states utilize an infinite CSS-based sweep line across analytical cards using a cyan linear-gradient stroke.
