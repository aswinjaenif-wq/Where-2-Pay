# Where 2 Pay Frontend

This is the missing frontend application for the supplied Where 2 Pay backend.

## Run

1. Open a terminal in this folder.
2. Run `npm install`.
3. Start the supplied backend first from `w2p_backend` with `npm install` then `npm run dev`.
4. Start this frontend with `npm run dev`.
5. Open the Vite URL shown in the terminal.

Optional: create `.env` with `VITE_API_BASE=http://localhost:5000/api` if your API runs elsewhere.

## Included
- React + Vite application structure
- Message scan
- URL scan
- Payment request scan
- QR upload/scan API integration
- Scan result/risk display
- Incident report creation
- History retrieval and clearing
- Responsive dark cyber-guard UI
